# Ayan Pathan — Developer Portfolio

> Personal portfolio website showcasing my experience, projects, technical skills, and work as a Full Stack & Mobile Application Developer.

## Overview

This repository contains the source code for my personal developer portfolio.

The portfolio is built to present my professional experience, selected projects, technical skills, education, and the technologies I work with across frontend, backend, mobile development, and cloud infrastructure.

Rather than being a collection of demo projects, the portfolio focuses on the kind of software I build in real-world environments — production applications, APIs, dashboards, integrations, performance improvements, and scalable application architecture.
